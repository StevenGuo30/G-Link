G-Link · 连接这件事，简单一点就好。
================================

1. 完整解压 ZIP，打开「G-Link.app」。
2. 按首次设置导入配置：私人包可以选择「使用随包配置」。
   公开版没有私人节点，需要自行获取 .qinglink / sing-box JSON 配置。
3. 点击「开启」，按 macOS 提示授权修改网络设置。
4. 用完点「关闭」；正常退出G-Link也会先恢复原设置。
5. 更新时打开「帮助 → 检查更新」，按提示安装并重启，配置会保留。

详细动画教程：打开「教程」文件夹中的「使用指南.html」。
配置完成后，可以在应用里点「添加到应用程序」。
接收者不需要安装 Homebrew、Python 或命令行开发工具。

第一次被 macOS 拦截：本版本使用本地签名，没有苹果 Developer ID 公证。
确认来源可信，先尝试打开，再到“系统设置 → 隐私与安全”按提示允许。
修改系统代理时的管理员密码授权是另一件事，不能代替苹果公证。
不必关闭 Gatekeeper，不必执行移除 quarantine 的命令。

注意：
• 旧工具包请先运行 04 停止；不要同时开启多个代理工具。
• 关闭窗口后，应用还会在菜单栏运行。
• 异常退出或重启后网络异常：重开G-Link，点击“恢复连接”。
• 恢复成功前不要删除 ~/Library/Application Support/QingLink 内的备份。
• 这是系统代理；不包含智能分流或 TUN，不保证接管每个程序。
• 连接配置含私人服务器信息，请勿公开发布。
